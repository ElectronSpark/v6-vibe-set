# Linux GUI / KDE Inventory

Last updated: 2026-06-24.

This inventory is the working map for KDE/Qt/Chromium GUI ABI work. It keeps
the ownership boundary explicit:

- GUI behavior belongs first in Linux-compatible kernel ABI, libc/sysroot,
  rootfs data, or build/staging policy.
- KDE, Qt, KWin, Plasma, Chromium, WebKit, and other imported user programs are
  probes or upstream payloads. They should not gain behavioral xv6 source
  patches.
- Weston is a regression/control package only for the current KDE direction;
  do not modify it unless explicitly requested.

## Current Upstream-Clean Boundary

Allowed xv6-specific userland surfaces:

```text
user/lib
user/lib/x86_64
ports/libudev
ports/libseat
ports/libevdev
ports/libinput
ports/xv6-gbm
ports/wayland
scripts/image/*
rootfs-overlay/*
```

Behavioral fixes for KDE/Qt/Chromium should be reduced to one of these layers:

```text
kernel Linux ABI
libc/sysroot behavior
Linux headers and package metadata
rootfs data
build/staging wrappers
local xv6-owned compatibility shims
```

Imported KDE/Qt/KWin/Plasma/Chromium/WebKit source should remain upstream-clean
except marker-only xv6 metadata.
